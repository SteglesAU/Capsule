What this is. A faithful mockup of the actual built React Native screens (Onboarding, Locked/capture home, Review Mode, Settings), rendered on the web so it can be reviewed without an iOS build.

v1 scope: everything shown here is on-device and offline — local encrypted storage, biometric-gated review, a daily time-lock cycle. No accounts, no cloud.  Paid tier (later): cloud backup & multi-device sync layered on top.

Status: the app is ~90% built but dormant since May and never shipped. See the build plan (CAPSULE_BUILD_PLAN.md) for the gap list to a TestFlight-ready MVP — the key items are real at-rest encryption (currently aspirational), a fix so Settings can actually change the schedule, app icon/splash assets, and EAS build config.
